# Сервис сборки ПК — веб-API

Дубовский Эльдар, ВПК-7, практическая работа № 4.

Веб-API на ASP.NET Core (.NET 10) хранит конфигурации ПК в PostgreSQL, проверяет совместимость деталей и рассчитывает мощность блока питания. Каталог и цены сервис получает по HTTP из API магазина.

В `src/PcAssembly.Api` находятся HTTP-маршруты, доступ к базе и клиент магазина. `src/PcAssembly.Domain` содержит общие контракты и правила подбора. `amvera.yml` указывает Dockerfile и порт `8080` внутри контейнера.

## Развёртывание в Amvera

Подключите этот репозиторий к приложению Amvera. Приложение и PostgreSQL разместите в одном регионе. Во вкладке «Переменные» приложения задайте следующие настройки.

| Имя | Назначение |
| --- | --- |
| `ConnectionStrings__AssemblyDb` | Секрет со строкой подключения к PostgreSQL. В `Host` укажите внутренний адрес базы для чтения и записи |
| `Database__Initialize` | `true` для создания таблиц в пустой базе при первом запуске |
| `Integration__ServiceKey` | Секрет со случайным ключом от 20 символов. Тот же ключ должен быть настроен у магазина |
| `Shop__BaseUrl` | Адрес магазина или ShopStub для проверки сценариев, которые получают каталог и цены |

После запуска по HTTPS-домену приложения проверьте `GET /health` и `GET /health/ready` в Postman. Оба маршрута должны вернуть `200 OK`. Документация API доступна по `/swagger`.
